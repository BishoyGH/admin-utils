## 10. Definition of Done (per feature)

- [ ] Acceptance criteria written and linked to feature ID
- [ ] Backend unit + integration tests; frontend unit/component tests
- [ ] E2E test for the primary user journey (P0/P1)
- [ ] Security tests added (authz at minimum; injection where inputs exist)
- [ ] Works on v15 and v16 (CI green on both)
- [ ] LTR and RTL screenshots reviewed; a11y check passed
- [ ] Audit log entries for all mutating actions
- [ ] Feature-flagged; default state documented
- [ ] Docs and i18n strings (EN + AR) updated
- [ ] Performance within budget; no new lint/type errors
- [ ] Reviewed by at least one other developer (two for privileged features)
