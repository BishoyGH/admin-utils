# Definition of Ready (per task)

- [ ] Acceptance criteria written in the task (Given/When/Then; happy path + denied/invalid path)
- [ ] API / doctype / props contract written and approved in `docs/contracts/`
- [ ] Referenced tasks and module prerequisites are done or available
- [ ] Test list agreed (unit, integration, e2e for P0/P1, security, a11y)
- [ ] Permissions, feature flag and audit events identified
- [ ] For privileged modules: design approved by a human (`privileged-review.md`)

Then set status `ready`.
