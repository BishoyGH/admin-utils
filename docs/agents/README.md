# Agent roles

- [Architect](architect.md) — Module boundaries, contracts, ADRs, compat-layer design.
- [Implementer (backend)](implementer-backend.md) — Services, API endpoints, doctypes, patches.
- [Implementer (frontend)](implementer-frontend.md) — Vue pages, components, composables, i18n, RTL.
- [Test author](test-author.md) — Unit, integration, functional, e2e, security and visual tests from the task test list.
- [Security reviewer](security-reviewer.md) — Authorization matrix, injection review, secrets handling, privileged-feature review.
- [Compatibility agent](compatibility.md) — v15/v16 differences, CI matrix failures, upgrade tests.
- [UX / accessibility reviewer](ux-a11y.md) — Keyboard, ARIA, contrast, Arabic/RTL screenshots.
- [Docs agent](docs.md) — Docs pages, changelog, in-app help (KNOW).
- [Release agent](release.md) — Versioning, packaging, release notes.

Work package = 3 to 10 related tasks from one module, small enough to review in one sitting.
